# FURIACSInfo: Python Telegram Bot

Telegram bot em Python com objetivo de informar o usuário sobre o time de CS da FURIA.


## Instruções de uso (ZIP-IDE)

1. Code -> Download ZIP.

2. Extrair `FURIACSInfoBot-main.zip`.

3. Abrir `FURIACSInfoBot-main` pasta e extrair `furai.zip`.

4. Abrir `FURIACSInfoBot-main` com IDE.

5. Baixar depenências (terminal):
```bash
  pip install -r requisitos.txt
```

6. Iniciar o bot (terminal):
```bash
  python bot.py
```

7. Iniciar `index.html` com o navegador (ou acessar o site hospedado) e clicar em "Acessar Chatbot" (ou acessar diretamente via [Link Telegram](https://t.me/furiachat64bot).

8. Clicar em "Start Bot".

9. CLicar em "Start" ou digitar no chat do Telegram:

```bash
  /start
```


## Recursos Utilizados

- Python (telegram-bot, dotenv, requests)
- PandaScore API
- BotFather (telegram)
